Put your photo here as `portrait.jpg`.

- Square crop works best — it's displayed in a circle.
- Around 600×600 px is plenty. Keep it under ~300 KB so the page stays fast.
- Any name other than `portrait.jpg` won't be picked up; either rename the file
  or change the `portrait.src` line in `index.html`.

Until a photo is here, the page shows your initials in a circle instead — so it
never looks broken.
